Asymptote Language Support

LSP-based VS Code extension for the Asymptote vector graphics language — code completion, real-time diagnostics, go-to-definition, and more.

Install from Marketplace View on GitHub

Features

✨

Code Completion

Built-in types, functions, control-flow snippets, and symbols from imported modules — all at your fingertips.

🔍

Go-to-Definition

Jump to definitions across imported modules. Resolves import, include, access statements.

⚠

Real-time Diagnostics

Unmatched brackets, unresolved imports, and optional semicolon hints — as you type, no save needed.

🎨

Semantic Highlighting

Fine-grained token coloring: functions, types, parameters, and constants — zero config.

📝

Signature Help

Parameter hints for built-in functions — all overloaded signatures shown at a glance.

🔧

Code Formatting

Configurable brace style, indent size, and path expression spacing.

💡

Hover Information

Type signatures and module sources on hover. Built-in constants and keywords documented inline.

🎯

Compile & Preview

One-click compilation. SVG inline preview, PDF in split view, auto-compile on save.

🛠

Rename & References

Rename symbols across all files. Find all references across current file and imported modules.

🌈

Color Preview

Inline swatches for named Asymptote colors and rgb(…) expressions.

Quick Start

  1. 1. Install the extension from the VS Code Marketplace. ext install asy-lsp.asymptote-lsp
  2. 2. Open or create a .asy file — syntax highlighting and completions activate automatically.
  3. 3. Import a standard library module — its symbols will be available in autocomplete. import drawtree;
  4. 4. Press F12 to jump to definitions, F2 to rename, Shift+Alt+F to format.

Settings

asymptote.searchPaths

Additional import search directories. Automatic system library discovery via kpsewhich.

asymptote.asyPath

Path to the asy executable for compilation and preview.

asymptote.compile.outputFormat

Output format: svg, pdf, or png. SVG is recommended.

asymptote.formatting.*

Brace style, indent size, tabs vs spaces, path expression spacing.
